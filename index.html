Selected Publications

A Robust Machine Learning Framework for Anomaly-Based Intrusion Detection in Software-Defined Networks

Muhammad Hanif Hussain Khan, Arsalan Khan, Saif Ullah Noor, Wasiat Khan, Amjad Khan

Spectrum of Engineering Sciences, Vol. 4 No. 3 (2026)

SDN Intrusion Detection ANN Random Forest XGBoost CIC-IDS-2017

This study proposes an anomaly-based intrusion detection framework for Software-Defined Networks using ensemble machine learning and deep learning techniques. Using the CIC-IDS-2017 dataset with SMOTE-based balancing and normalization, the custom ANN achieved 99.80% accuracy, outperforming classical models including Random Forest, SVM, and XGBoost.

Machine Learning-Based Threat Detection in Low-Resource Urdu Tweets: Comparative Evaluation of Classical Models

Amjad Khan, Saif Ullah Noor, Reyan, Jawad Ahmad, Hilal Khan

Spectrum of Engineering Sciences, Vol. 4 No. 1 (2026)

NLP Urdu Threat Detection TF-IDF SVM

This research investigates automated threat detection in low-resource Urdu tweets using classical machine learning approaches. The study evaluates Logistic Regression, Random Forest, Naive Bayes, and SVM on a manually annotated dataset of 3,170 tweets. SVM achieved the highest accuracy of 82.69%.

Deep Learning-Based Clinical Decision Support System for Automated Kidney Stone Detection in CT Images Using Custom CNN and Transfer Learning

Amjad Khan, Muhammad Javed, Nasir Gul, Saif Ullah Noor, Reyan, Ashraf Ullah

Kashf Journal of Multidisciplinary Research, Vol. 03, Issue 06 (2026)

Medical AI CNN Transfer Learning VGG16 CT Imaging

This work presents an automated clinical decision support system for kidney stone detection from CT images using a custom CNN and transfer learning. Evaluated on 3,154 annotated CT images, the custom CNN achieved 94.3% accuracy, while fine-tuned VGG16 reached 96.5%, demonstrating strong potential for AI-assisted radiological diagnosis.
